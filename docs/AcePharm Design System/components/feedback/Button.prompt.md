# Button

Reusable button element for actions, navigation, and form submission.

## Usage

```jsx
<Button variant="primary">Start revising free</Button>
<Button variant="secondary">Explore the platform</Button>
<Button variant="ghost">Learn more</Button>
<Button variant="danger">Delete</Button>
```

## Variants

- **primary**: Indigo background, white text. Primary call-to-action.
- **secondary**: White background, border. Secondary actions.
- **ghost**: Transparent, slate text. Tertiary actions, inline text.
- **danger**: Red background. Destructive actions only.

## Sizes

- **default**: 44px height, standard padding
- **sm**: 38px height, compact padding
- **lg**: 52px height, generous padding

## States

All variants support `disabled` state (45% opacity, no pointer events).
