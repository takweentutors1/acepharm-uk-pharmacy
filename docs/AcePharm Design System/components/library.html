AcePharm Component Library

Reusable React components for learner app and admin portal:

  • Buttons — primary, secondary, ghost, danger variants
  • Forms — input, select, checkbox, radio, textarea
  • Feedback — toast, modal, inline banner, error messages
  • Content — card, panel, grid, table, section wrappers
  • Question — option button, confidence selector, explanation layout
  • Ace UI — ask panel, thread display, quick prompts, citation blocks
