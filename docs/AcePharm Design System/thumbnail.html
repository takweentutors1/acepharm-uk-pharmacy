AcePharm Design System

A complete visual and component system for UK pharmacy education.

Created by pharmacists. Built for pharmacy students.

📖 Documentation

Complete design guide, token specs, component inventory, and accessibility rules.

🎨 Color System

Primary, semantic, and neutral palette with full hex values and usage rules.

✍️ Typography

Responsive font scale from display to micro, with weights and line heights.

📏 Spacing

8px-based scale with semantic tokens for padding, margin, and gaps.

🔘 Buttons

Primary, secondary, ghost, and danger variants across all sizes and states.

❓ Question Design

Multiple-choice option buttons with feedback states and confidence selectors.

🤖 Ace UI

Ask Ace panel, thread display, quick prompts, and citation blocks.

⚙️ Skill Prompt

Ready-to-use design system skill for Claude, with usage guidelines.

Quick Start

Begin with the readme.md for a complete overview of the brand, then explore the specimen cards above. All components are React-based and use CSS custom properties from styles.css.

This design system is the single source of truth for AcePharm's visual identity across the learner app, admin portal, and marketing site.
